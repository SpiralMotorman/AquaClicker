# Contributing to AquaClicker 🌊

First off, thank you for considering contributing to AquaClicker! It's people like you that make AquaClicker such a great tool.

## How Can I Contribute?

### 1. Reporting Bugs
* Ensure the bug has not already been reported by searching existing [Issues](#).
* If you find a bug, open a new Issue using the **Bug Report** template.
* Include detailed steps to reproduce the problem, your OS version, and AquaClicker version.

### 2. Suggesting Enhancements
* Check existing issues to make sure your feature hasn't been requested already.
* Open a new Issue labeled `enhancement` and describe the feature, why it’s useful, and how it should work.

### 3. Pull Requests (PRs)
1. **Fork** the repository.
2. **Create a branch** for your feature or fix: `git checkout -b feature/amazing-feature`.
3. **Commit** your changes with clear messages: `git commit -m 'Add new hotkey binding feature'`.
4. **Push** to your branch: `git push origin feature/amazing-feature`.
5. Open a **Pull Request** targeting the `main` branch.

## Code Style & Standards

* Follow standard coding conventions for the language used.
* Ensure all code is clean, well-documented, and well-tested.
* Keep commit messages concise and descriptive.

Please note that this project is adhering to our [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
