# Security Policy 🛡️

## Supported Versions

Only the latest release of AquaClicker receives security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or security-related issue, please **do not** open a public issue.

Instead, please send an email to **your-security-email@domain.com** or submit a private security advisory through GitHub.

### What to include:
* Description of the issue and its impact.
* Step-by-step instructions or proof of concept to reproduce the issue.
* Any potential mitigations or patches if available.

We will review your submission and respond within 48 hours.

---

## ⚠️ Anti-Virus False Positives Note

Because AquaClicker simulates global mouse inputs and hooks global system keypresses (hotkeys), some anti-virus software may flag the executable as a false positive (e.g., generic auto-clicker or keylogger heuristic). 

All code is open-source and can be inspected directly in this repository.
